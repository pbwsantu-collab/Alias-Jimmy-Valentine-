# Alias Jimmy Valentine

Interactive bilingual (English + Bengali) textbook for O. Henry’s short story *A Retrieved Reformation* / *Alias Jimmy Valentine*.

Designed for WBCHSE Class 11 / HS English (Semester) students.

## Features

- **Click any word** in the story text → popup with:
  - Pronunciation
  - Part of speech
  - **বাংলা অর্থ** (Bengali meaning)
  - Simple English meaning
  - Context in the story
  - Example sentence
- Rich vocabulary bank (~700 entries) including story-specific terms and high-frequency function words
- Paragraph-level explanations in English + Bengali
- Characters, themes, critical analysis
- Short Answer & Broad questions with model answers
- Quizzes (vocabulary, story, characters, themes, events, literary devices)
- Progress tracking & revision sheet
- Dark mode + high-contrast mode
- Works offline once loaded (PWA-style)

## How to use

1. Open `index.html` in a browser (or host the folder on any static server / GitHub Pages).
2. Click **Start Learning** → **Read the Story**.
3. Tap any English word to see its Bengali meaning and details.
4. Use the bottom navigation for Vocab Bank, Questions, Progress, etc.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Full self-contained interactive lesson |
| `vocab-extra.js` | Extra / story-specific vocabulary (auto-merged) |
| `vocab-function-words.js` | High-frequency function words (auto-merged) |
